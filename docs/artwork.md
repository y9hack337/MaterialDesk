# Bundled Artwork

## Desktop Wallpaper

Asset: `app/src/main/res/drawable-nodpi/desktop_wallpaper.webp`.

Minimal dark Material 3 wallpaper supplied by the project owner as
`pixel-material3-minimal-dark-4k.png`. The bundled copy is 3840 x 2160 pixels,
encoded as lossless WebP (method 6) so its dark gradients do not band. It
contains no text or logo, and its low-contrast outline shapes keep white desktop
icon labels readable. The app decodes it without resource-density scaling, then
prepares a display-sized pixel frame.
